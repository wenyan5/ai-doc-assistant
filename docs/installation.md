# NovaDesk 安装说明

- 文档版本：2.1
- 更新日期：2026-09-01
- 适用产品：NovaDesk Desktop

## 系统要求

NovaDesk Desktop 支持 Windows 11 和 macOS 13 及以上版本。安装前需要至少 4 GB 可用内存、500 MB 磁盘空间和稳定的网络连接。当前版本不支持 Linux，也不能安装在手机或平板电脑上。

## 安装步骤

1. 登录 NovaDesk 官方网站并进入“下载”页面。
2. 根据操作系统选择 Windows 或 macOS 安装包。
3. 打开安装包并按照页面提示完成安装。
4. 启动 NovaDesk，使用注册邮箱登录。
5. 首次登录时，系统会自动下载基础配置。

## 安装限制

每个账户最多可以在三台电脑上激活 NovaDesk。更换电脑前，应先在“账户设置 → 已登录设备”中移除旧设备。如果安装程序显示错误代码 E101，应检查系统版本和剩余磁盘空间。

## 容易混淆的情况

卸载 NovaDesk 应用不会自动释放设备激活名额。用户必须进入“账户设置 → 已登录设备”移除旧设备，之后才能在第四台电脑上激活。重新安装应用也会继续占用原来的设备名额。
