# NovaDesk 用户权限说明

- 文档版本：2.1
- 更新日期：2026-09-03
- 适用产品：NovaDesk Workspace

## 权限角色

NovaDesk Workspace 提供三种用户角色：管理员、编辑者和查看者。

### 管理员

管理员可以邀请或删除成员、修改成员角色、调整工作区设置、管理账单以及导出全部工作区数据。每个工作区至少需要保留一名管理员。

### 编辑者

编辑者可以创建、修改和删除自己有权访问的文档，也可以与其他成员共享文档。编辑者不能查看账单、删除工作区或修改其他成员的角色。

### 查看者

查看者只能阅读已经分享给自己的文档，不能修改、删除、下载或再次分享文档。如果管理员开启“允许查看者下载”，查看者才可以下载 PDF 副本。

## 权限更新

管理员可以进入“工作区设置 → 成员管理”修改成员权限。权限变更通常会立即生效；已经登录的成员可能需要刷新页面。如果用户仍然看到旧权限，应退出账户后重新登录。

## 容易混淆的情况

“允许查看者下载”只允许查看者下载已经分享给自己的单个文档，不代表查看者可以导出整个工作区。无论是否开启下载权限，只有管理员可以申请完整的工作区导出。
