# NovaDesk 取消和退款说明

- 文档版本：2.2
- 更新日期：2026-09-15
- 适用产品：NovaDesk Cloud

## 取消订阅

工作区管理员可以进入“账单设置 → 当前方案”，点击“取消订阅”。取消后，付费功能会继续保留到当前计费周期结束，不会立即停止。

普通成员、编辑者和查看者不能取消工作区订阅。删除 NovaDesk 应用或删除个人账户，也不会自动取消工作区订阅。

## 月度方案退款

月度方案通常不提供退款。发生重复扣款或系统计费错误时，管理员可以在扣款后的14天内联系账单支持申请审核。

## 年度方案退款

年度方案首次购买后7天内可以申请全额退款。超过7天后取消，剩余月份通常不退款，但付费功能会保留到年度周期结束。

## 取消后的数据

付费方案结束后，工作区会自动降级为免费版。如果成员数量或存储空间超过免费版上限，用户仍可以查看已有数据，但不能添加成员或上传新文件。数据不会因为取消订阅立即删除。
