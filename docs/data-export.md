# NovaDesk 数据导出说明

- 文档版本：1.8
- 更新日期：2026-09-18
- 适用产品：NovaDesk Cloud

## 可用导出格式

专业版和企业版支持导出数据。单个文档可以导出为 PDF，表格可以导出为 CSV。企业版管理员还可以将整个工作区导出为 ZIP 文件。

免费版不能使用批量导出功能，但文档所有者可以逐个下载自己创建的文档 PDF。查看者只有在管理员开启“允许查看者下载”后才能下载。

## 导出工作区

管理员进入“工作区设置 → 数据管理 → 导出工作区”，选择时间范围并提交申请。系统会生成一个下载链接，并发送到管理员的注册邮箱。

导出任务通常在30分钟内完成。超过 10 GB 的工作区可能需要最长24小时。下载链接有效期为48小时，过期后必须重新提交导出申请。

## 导出限制

编辑者不能导出整个工作区。已经放入回收站的文件默认不包含在导出结果中。审计日志仅包含在企业版导出中。导出文件可能包含敏感内容，下载后应存放在安全位置。
