# NovaDesk 错误代码说明

- 文档版本：2.4
- 更新日期：2026-09-12
- 适用产品：NovaDesk Desktop 和 NovaDesk Cloud

## E101 安装环境不兼容

E101 表示设备的操作系统版本过低、磁盘空间不足，或者安装包与当前系统不匹配。用户应确认设备满足安装要求，并重新下载正确的 Windows 或 macOS 安装包。

## E203 登录验证失败

E203 表示邮箱、密码或一次性验证码无效。用户应重新输入登录信息，并确认验证码没有过期。连续失败五次后，账户会锁定15分钟。

## E305 同步连接中断

E305 表示客户端无法连接 NovaDesk Cloud。用户应检查网络连接、关闭 VPN 后重试，并确认系统时间正确。如果问题持续超过30分钟，可以联系技术支持。

## E410 存储空间不足

E410 表示工作区已经达到当前方案的存储上限。用户可以删除不需要的文件、清空回收站或升级方案。仅删除文件但没有清空回收站，不会立即释放存储空间。

## 联系支持

联系支持时应提供错误代码、出现时间、操作系统版本和问题发生前的操作步骤。不要在支持请求中发送密码或一次性验证码。
